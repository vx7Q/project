# gosogood.xyz

A clean, modern landing page.

## Features

- Intro splash animation
- Language switcher (TH / EN / ZH)
- Light / Dark theme toggle
- Prism mesh background
- Floating particles
- Scroll progress bar
- Back to top button
- Smooth animations

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

Open `index.html` in your browser, or serve with any static server:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```
